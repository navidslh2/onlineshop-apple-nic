#  فروشگاه آنلاین Apple-Nic 

این پروژه یک نسخه از سایت (https://apple-nic.com)  است که با استفاده از Next.js MySQL2 Tailwind  nextauthو Framer Motion ساخته شده است.   
در این پروژه تلاش کرده‌ام سایت اپل‌نیک را با دقت و کیفیت بالا بازسازی کنم.



##  ویژگی‌ها

-  طراحی کاملاً واکنش‌گرا (Responsive) با Tailwind   
-  انیمیشن‌های روان و حرفه‌ای با Framer Motion  
-  اتصال به پایگاه داده MySQL با استفاده از mysql2  
-  صفحات داینامیک محصولات    
-  طراحی مدرن، تمیز و الهام‌گرفته از سبک Apple-Nic
-  این پروزه شامل سبد خرید لاگین جستجو فروش ویژه و ... میباشد
